3. AGREED DECISIONS
============================================================
- Framework: Next.js 16.4.6 App Router, React 19, TypeScript, Tailwind CSS v4.
- Language: Nova replies in Bangla (Bengali script). UI labels are Bangla.
- API contract (English error strings per spec):
    POST /api/chat  { "message": "...", "sessionId": "..." }
    200 { "reply": "..." }
    400 { "error": "Invalid request" }
    503 { "error": "Nova is temporarily unavailable. Please retry." }
- AI: Google Gemini chat model + Google embedding model via @langchain/google-genai.
- Agent: LangGraph createReactAgent, tools search_knowledge + execute_task.
- RAG: Qdrant collection `my_custom_agent_db`, cosine distance, dimension detected at seed time.
- Memory: LangGraph thread_id = sessionId. PostgresSaver default, MemorySaver only for smoke tests.
- API keys are NOT available yet. The app must build and degrade gracefully with 503.
- Voice: browser Web Speech API only. No server voice services.
- No auth, no rate limiting, no audit logging, no admin UI (per requirements).

2026-11-24 Claude Code: REVIEW of backend + checks. Role = reviewer only, no src edits.
  Ran: npm run typecheck / npm run lint. Findings for OpenCode to apply:
  [BLOCKER] package.json "typecheck": "tsc --noEmit" fails on src/app/layout.tsx
     (LayoutProps is generated by Next typegen). Use: "next typegen && tsc --noEmit".
  [BLOCKER] lint: react-hooks/set-state-in-effect errors in ChatBox.tsx:98 and
     useSpeechSynthesis.ts:25. Fix without disable comments: detect support with
     useSyncExternalStore(() => () => {}, () => "speechSynthesis" in window, () => false);
     read localStorage via lazy useState initializer is NOT SSR-safe, so keep the effect
     but wrap with a mounted check or use useSyncExternalStore for the stored values.
  [HIGH] src/lib/ai/agent.ts preModelHook trims to last N messages and only skips
     leading "tool" messages. If the window starts on an "ai" message, Gemini rejects
     the request (contents must start with a user turn; @langchain/google-genai
     common.js:251 also throws "requires alternate messages between authors").
     Fix: advance `start` to the first message whose getType() === "human".
  [HIGH] Timeout/abort (route.ts deadline) can leave a checkpoint whose last message is a
     HumanMessage or an AIMessage with tool_calls but no ToolMessage. The next turn on that
     sessionId then fails forever (two consecutive user turns / dangling tool call) ->
     session permanently 503. Fix: in preModelHook drop trailing-unanswered AI tool_calls
     and merge/skip consecutive human messages, or on abort don't persist (invoke with
     durability / catch and append a fallback AIMessage via graph.updateState).
  [MED] memory.ts/agent.ts cache the RESULT, not the in-flight promise: concurrent first
     requests create multiple pg Pools + graphs. Cache the promise (and clear on reject).
  [MED] src/lib/db/qdrant.ts ensureCollection: create a keyword payload index on
     "metadata.source" (client.createPayloadIndex). pruneStaleSourcePoints filters on it,
     and Qdrant Cloud strict mode can reject filtered deletes on unindexed fields ->
     re-seed would fail.
  [LOW] embeddings.ts: use taskType RETRIEVAL_DOCUMENT for ingest and RETRIEVAL_QUERY for
     search_knowledge (better recall; same model, so dimensions unchanged).
  [LOW] route.ts maxDuration=60 but REQUEST_TIMEOUT_MS allows up to 120000; clamp to <60s.
  [LOW] createReactAgent (@langchain/langgraph/prebuilt) is deprecated in LangGraph v1
     in favour of createAgent from "langchain". Works now; fine for the demo.
  [OK] /api/chat contract, 400/503 handling, no stack traces leaked, execute_task
     ACT-XXXXXXXX + dev log, idempotent deterministic point IDs, dimension mismatch error.
